首次使用：连接 GitHub 登录

后台页面已准备好，登录服务尚未连接。完成以下一次性配置后，此页面会显示 GitHub 登录入口。

  1. 创建并发布 Qiuxu00/qiuxu00.github.io 仓库中的网站。
  2. 按项目 oauth/README.md 部署 Cloudflare Worker，并创建 GitHub OAuth App。
  3. 将 Worker 的 HTTPS 地址填入 admin/settings.json 的 oauth_base_url，提交后等待网站发布。

OAuth Client Secret 仅保存在 Cloudflare 服务端的 Secrets 中。登录完成后仍由 GitHub 验证仓库写入权限。
